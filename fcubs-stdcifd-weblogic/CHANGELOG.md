# Changelog

## 1.0.0

- Added WebLogic Servlet bridge for raw FCUBS-style XML and SOAP 1.1/1.2 envelopes.
- Added Stateless EJB service with container-managed transactions.
- Added JNDI DataSource integration (`jdbc/FCUBSDS`).
- Added clone-owned PL/SQL XML adapter `STPKS_STDCIFD_WS` delegating to `STPKS_STDCIFD_MAIN`.
- Added authenticated WebLogic principal, branch check, maker/checker role checks, CSRF protection, and secure XML parsing.
- Bundled the Customer UI assets and sample SOAP requests.
